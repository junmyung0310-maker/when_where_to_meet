# When2Meet & Where2Meet (우리지금만나)

약속 시간 조율(When2Meet)과 최적의 대중교통 중간 장소 추천(Where2Meet)을 결합한 파이썬 기반 웹 서비스입니다.

---

## 🌐 접속 주소 및 네트워크 공유 안내

서버를 구동하면 `0.0.0.0:8000`으로 바인딩되어 **내 컴퓨터뿐만 아니라 같은 와이파이/네트워크에 있는 다른 컴퓨터, 노트북, 스마트폰**에서도 바로 접속할 수 있습니다.

### 1. 접속 주소 형식
- **내 컴퓨터 접속**: `http://localhost:8000`
- **다른 사람 컴퓨터/스마트폰 접속**: `http://<내-로컬-IP>:8000` (예: `http://10.221.62.44:8000`)
- **직관적인 모임 주소**:
  - 생성 시 원하는 링크 입력 가능: `http://<IP>:8000/meet/capstone-team`
  - 자동 생성 시: `http://<IP>:8000/meet/meet-a1b2c3`
  - *(기존 `/room/...`으로 접속해도 자동으로 `/meet/...`으로 안전하게 연결됩니다)*

### 2. 서버 실행 방법
프로젝트 디렉터리(`C:\WW2meet`)에서 아래 명령어를 실행합니다:

```bash
python main.py
```

실행 시 터미널 콘솔에 접속 주소가 친절하게 출력됩니다:
```text
=================================================================
🚀 When2Meet & Where2Meet 서버 시작!
👉 내 컴퓨터 접속 주소:     http://localhost:8000
🌐 다른 컴퓨터/스마트폰 접속: http://10.221.62.44:8000
=================================================================
```

## 📋 핵심 변경 및 구현 기능 상세

### 1. 직관적인 모임 주소 (URL) 지원
- 방 생성 시 **"나만의 모임 링크 주소 (선택)"** 입력란을 제공하여 기억하기 쉬운 주소(예: `/meet/team-meeting`, `/meet/capstone2026`)를 직접 지정할 수 있습니다.
- 미입력 시 `meet-xxxxxx` 형태의 깔끔한 코드가 자동 부여됩니다.
- 화면 우측 상단의 **[🔗 모임 링크 공유하기]** 버튼을 누르면:
  - **다른 컴퓨터/스마트폰 공유용 주소** (`http://10.221.62.44:8000/meet/...`)
  - **내 컴퓨터용 주소** (`http://localhost:8000/meet/...`)
  를 한눈에 확인하고 바로 복사할 수 있습니다.

### 2. 필수 참석자(VIP) 선택 방식 개편 ★
- **1단계: 자유로운 시간 등록**
  - 각 팀원은 내 가능 시간 입력창에서 오직 **자신의 이름과 가능한 시간대만 드래그로 색칠하여 등록**합니다. (등록 단계에서 번거로운 필수 참석자 체크 불필요)
- **2단계: 참여자 리스트에서 필수 참석자 동적 선택**
  - 팀원들이 일정을 등록하면 우측 종합 시간표 아래 **[⭐ 필수 참석자(VIP) 지정]** 섹션에 참여자 리스트가 체크박스 형태로 나타납니다.
  - 회의에 꼭 와야 하는 사람(예: 교수님, 조장, 발표자 등)의 이름을 체크하면:
    - **종합 시간표 실시간 반응**: 체크된 필수 인원 전원이 가능한 시간대에 **골드 테두리(⭐)**가 즉시 표시됩니다.
    - **AI 최적 모임 시간대 TOP 3 자동 갱신**: 필수 인원이 모두 참여할 수 있는 연속 시간대를 최우선으로 상단 TOP 3 추천 목록이 실시간 재계산됩니다.
  - 체크를 끄거나 바꾸면 즉시 모든 화면에 동적으로 반영됩니다.

### 3. 마우스 & 모바일 터치 드래그 인터랙션
- 30분 단위 셀 클릭 및 드래그로 빠르게 시간을 칠하고 지울 수 있습니다.
- 모바일/태블릿 화면에서도 손가락 터치 드래그를 지원합니다.

### 4. 실시간 호버 상세 안내 & 참여자별 시간표 하이라이트
- 종합 시간표의 특정 시간대에 마우스를 올리면 **가능 인원 수, 가능 참석자 명단(초록색 및 별표), 불가능 참석자 명단**이 표시됩니다.
- 우측 하단 참여자 명단에서 특정 사람의 이름에 마우스를 올리면 **그 사람만 가능한 시간대가 시간표에서 하이라이트**됩니다.

### 5. Where to Meet (장소 추천 UI 프리뷰 영역)
- 상단 탭에서 **[📍 Where to Meet (장소 찾기)]** 탭 전환 가능
- 모임 목적 선택 (스터디/회의, 카페/카공, 식사/회식, 뒤풀이/주점)
- 등록된 팀원 명단과 연동된 출발지 입력 필드
- 대중교통 이동시간 공평성 차트 (편차 최소화 시각화) 및 가상 지도 플레이스홀더
- 모임 시간에 맞춰 영업 중인 추천 장소 목록 카드 3곳 프리뷰
